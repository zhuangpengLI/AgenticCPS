# AgenticCPS 图标设计

## 目标

为 AgenticCPS 创建一枚在管理后台导航栏、用户头像和租户头像中保持清晰辨识度的品牌图标，并替换当前遗留头像和 Logo。

## 视觉概念

图标采用“AI 芯片 + 返利循环箭头”的组合：

- 中央 AI 芯片代表 AgenticCPS 的智能能力与 Agent 调用能力。
- 外围两段循环箭头代表商品推广、成交、返利和再次消费形成的 CPS 业务闭环。
- 不加入文字，避免在 24px 至 40px 的小尺寸场景中产生模糊和拥挤。

## 视觉规范

- 外形：圆角方形徽标。
- 主背景：深海蓝 `#071E3D`。
- 主图形：电光青 `#20E3D2`。
- 风格：现代、简洁、专业，允许轻微立体层次，但不使用复杂纹理或写实效果。
- 构图：芯片居中，循环箭头围绕芯片形成明确闭环；主体周围保留安全边距。
- 禁止项：文字、渐变过多、细碎电路线、金币堆叠、卡通人物、水印和高频背景纹理。

## 输出资产

- 生成一张 1024×1024 的高质量方形主图。
- 保存项目使用的 PNG 图标，确保缩放至 24px、32px 和 40px 时仍清晰。
- 如生成图包含不需要的背景边缘，进行裁切和尺寸适配，但不改变已确认的核心构图。

## 替换范围

- 管理后台左上角品牌 Logo：`frontend/admin-vue3/src/assets/imgs/logo.png`。
- 管理后台右上角用户默认头像：`frontend/admin-vue3/src/assets/imgs/avatar.gif` 的消费路径或等效的新 PNG 资源。
- 登录页、锁屏页、首页和消息区域中复用默认头像的场景。
- 当前本地数据库中主租户管理员的头像字段，使已登录用户重新登录后显示新图标。
- 新建数据库的默认管理员头像种子数据，避免新环境继续引用旧远程头像。

## 数据与兼容边界

- 已上传个人头像的普通用户保持不变；仅替换默认头像和主租户管理员头像。
- 不修改租户名称、用户名、权限或业务数据。
- 数据库头像使用前端可稳定访问的资源地址；若当前部署方式不支持前端静态资源绝对地址，则保留前端默认头像回退机制。
- 保持现有 Vue 组件接口不变，优先替换资源和默认值，不引入新依赖。

## 验收标准

- 左上角、右上角和默认租户管理员头像显示同一 AgenticCPS 图标。
- 图标在深色侧边栏与白色顶栏上均有清晰边界。
- 24px、32px、40px 三种尺寸下，芯片和循环箭头仍能被识别。
- 页面不存在旧的芋道头像或失效远程头像。
- 新建数据库与当前本地数据库的默认管理员头像保持一致。
- 相关资源可被前端构建解析，且修改文件通过 UTF-8 与差异检查。

## 验证方式

- 检查生成图片尺寸、色彩和小尺寸缩略图。
- 搜索默认头像和 Logo 的全部引用，确认替换范围完整。
- 校验当前数据库管理员头像字段。
- 运行前端资源解析或生产构建；若全量类型检查受仓库既有错误影响，单独记录验证缺口。
- 启动页面后对左上角 Logo、右上角头像和首页默认头像进行截图复核。
