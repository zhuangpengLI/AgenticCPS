## 1. 大淘客（Dataoke）配置流程

### 1.1 架构概览

AgenticCPS 项目中，**淘宝、京东、拼多多**三个平台的适配器均基于大淘客开放平台 API 实现，共用同一个基础 URL，采用统一的 MD5 签名鉴权机制。抖音联盟为桩实现，暂未对接大淘客。

```
基础URL: https://openapi.dataoke.com/api
签名算法: MD5(appKey={appKey}&timer={timer}&nonce={nonce} + appSecret)
```

#### 适配器一览

| 适配器类 | 平台编码 | API路径前缀 | 实现状态 |
|---------|---------|------------|---------|
| `TaobaoPlatformClientAdapter` | `taobao` | `/goods/`, `/tb-service/` | 已完成（大淘客原生API） |
| `JdPlatformClientAdapter` | `jd` | `/dels/jd/` | 已完成（大淘客聚合API） |
| `PddPlatformClientAdapter` | `pdd` | `/dels/pdd/` | 已完成（大淘客聚合API） |
| `DouyinPlatformClientAdapter` | `douyin` | - | 桩实现，未对接 |

### 1.2 获取大淘客 API 密钥

1. 前往大淘客开放平台注册账号：https://www.dataoke.com/pmc/
2. 在控制台创建应用，获取 **AppKey** 和 **AppSecret**
3. 如需京东联盟功能，还需获取京东推客的 **unionId**（授权key）
4. 淘宝联盟需配置 **推广位 PID**（adzoneId）

### 1.5 大淘客签名机制

所有适配器共用同一签名逻辑，以 `TaobaoPlatformClientAdapter#doGet` 为例：

```java
// 1. 生成时间戳和6位随机数
String timer = String.valueOf(System.currentTimeMillis());
String nonce = String.format("%06d", new Random().nextInt(1000000));

// 2. 拼接待签名字符串
String urlParamStr = String.format("appKey=%s&timer=%s&nonce=%s", appKey, timer, nonce);

// 3. 计算 MD5 签名 = md5(参数字符串 + appSecret)
String sign = DigestUtil.md5Hex(urlParamStr + appSecret).toLowerCase();

// 4. 将签名参数加入请求参数
allParams.put("appKey", appKey);
allParams.put("timer", timer);
allParams.put("nonce", nonce);
allParams.put("signRan", sign);
```

#### 签名流程图

```
┌─────────────┐     ┌──────────────┐     ┌────────────┐     ┌──────────────┐
│ 生成时间戳   │ ──▶ │ 拼接参数字符串 │ ──▶ │ MD5签名计算 │ ──▶ │ 组装完整请求 │
│ timer+nonce │     │ appKey&timer │     │ +appSecret │     │ GET请求发送  │
└─────────────┘     │ &nonce       │     └────────────┘     └──────────────┘
                    └──────────────┘
```

### 1.7 缓存策略

平台配置使用 Redis 缓存，由 `CpsCacheConfig` 管理：

| 缓存名称 | Key格式 | TTL | 说明 |
|---------|---------|-----|------|
| `cps:platform` | `cps:platform::{platformCode}` | 30分钟 | 平台配置缓存 |
| `cps:rebateConfig` | `cps:rebateConfig::*` | 10分钟 | 返利配置缓存 |
| `cps:riskRateRule` | `cps:riskRateRule::*` | 5分钟 | 风控频率规则缓存 |

**缓存流程**：
1. 查询：先查缓存，命中返回；未命中查数据库并回填
2. 更新：更新平台配置时主动失效缓存（`@CacheEvict`）

### 5.3 必测场景清单

对于每个平台适配器，需覆盖以下场景：

| 场景 | 说明 | 预期结果 |
|------|------|---------|
| 平台配置不存在 | `getPlatformByCode` 返回 null | searchGoods 返回空结果，generatePromotionLink 返回 null，queryOrders 返回空列表，testConnection 返回 false |
| 搜索参数映射 | 验证排序、价格区间、优惠券等参数正确传递 | 请求参数包含对应字段 |
| 转链参数映射 | 验证 goodsId、adzoneId、channelId 传递 | 请求参数包含对应字段 |
| 订单参数映射 | 验证时间范围、分页参数传递 | 请求参数包含对应字段 |
| HTTP 异常 | 网络超时或服务不可用 | 返回空结果，不抛异常 |
| 响应解析失败 | API 返回非预期格式 | 返回空结果，记录错误日志 |

### 5.4 项目约束

| 约束项 | 规范 | 说明 |
|--------|------|------|
| 金额字段 | Integer（分） | 不使用 Double/BigDecimal 存储金额 |
| 时区 | Asia/Shanghai | 数据库和 JVM 时区一致 |
| 租户隔离 | 所有查询包含 tenant_id | MyBatis Plus 自动处理 |
| 软删除 | `deleted` 字段 | 不硬删除 CPS 数据 |
| 日志前缀 | `[平台适配器]` | 如 `[淘宝适配器]`、`[京东适配器]` |
| HTTP 超时 | 5000ms | `HttpRequest.get(url).timeout(5000)` |
| 响应成功码 | `"0"` | `response.path("code").asText()` 等于 `"0"` |
