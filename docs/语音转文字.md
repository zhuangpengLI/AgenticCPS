在 uni-app 中保存录音音频并通过自建识别接口转文字，主要流程如下：

## 跨域处理

H5 页面不能直接从 `localhost:3000` 请求未返回 CORS 响应头的 ASR 服务。项目已在 `frontend/mall-uniapp/vite.config.js` 配置 `/asr-proxy` 开发代理：开发环境请求同源路径，由 Vite 转发到 `SHOPRO_ASR_TARGET`。

生产环境请在 Nginx 或网关配置同源反向代理，例如：

```nginx
location /asr-proxy {
    proxy_pass http://47.109.140.45:8080/SenseVoice/api/v1/asr;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}
```

然后将生产环境的 `SHOPRO_ASR_URL` 设置为站点同源地址（例如 `/asr-proxy` 或 `https://你的域名/asr-proxy`）。如果必须让浏览器直连 ASR 服务，则需要在 ASR 服务端启用 CORS，至少允许实际前端 Origin，并处理 `OPTIONS` 预检请求。

使用录音管理器 uni.getRecorderManager() 进行录音；

录音结束后获取临时文件路径；

保存音频：可以根据需求保存到本地（如保存到相册或文件系统）或直接上传到服务器；

上传音频到识别接口：使用 uni.uploadFile 将音频文件以 multipart/form-data 格式上传；

接收接口返回的文字结果。

下面给出具体实现步骤和代码示例。

1. 录音并获取临时文件路径
javascript
// 获取全局唯一的录音管理器
const recorderManager = uni.getRecorderManager();

// 设置录音参数
const options = {
  duration: 60000,          // 最长录音时长（ms），默认60s
  sampleRate: 16000,        // 采样率，识别接口通常需要16k或8k
  numberOfChannels: 1,      // 单声道
  encodeBitRate: 48000,     // 编码码率
  format: 'mp3'             // 格式：mp3 / aac / wav，根据接口要求选择
};

// 开始录音
recorderManager.start(options);

// 监听录音结束事件
recorderManager.onStop((res) => {
  const tempFilePath = res.tempFilePath; // 录音临时文件路径
  console.log('录音文件路径:', tempFilePath);
  // 在这里调用保存或上传函数
  saveOrUploadAudio(tempFilePath);
});

// 停止录音（可以绑定按钮触发）
function stopRecord() {
  recorderManager.stop();
}
2. 保存音频到本地（可选）
如果希望将录音保存到用户设备（如相册或文件系统），可以使用 uni.saveFile 或 uni.getFileSystemManager。

2.1 保存到小程序本地文件系统
javascript
function saveToLocal(tempFilePath) {
  uni.saveFile({
    tempFilePath: tempFilePath,
    success: (res) => {
      const savedFilePath = res.savedFilePath; // 本地持久路径
      console.log('保存成功:', savedFilePath);
    },
    fail: (err) => {
      console.error('保存失败', err);
    }
  });
}
注意：uni.saveFile 主要适用于小程序环境，且存储空间有限。App 端可使用 plus.io 或原生 API。

2.2 保存到系统相册（仅音频可能不支持，仅图片/视频）
音频一般不能直接保存到相册，但可以保存到文件目录。如果需要分享给用户，可以提示用户手动保存或使用 uni.share。

3. 上传音频到自建识别接口
使用 uni.uploadFile 将音频文件上传到服务器。

javascript
function uploadAudio(tempFilePath) {
  uni.uploadFile({
    url: 'https://your-api.com/recognize', // 你的识别接口地址
    filePath: tempFilePath,
    name: 'file',               // 接口要求的文件字段名
    header: {
      // 自定义请求头，如鉴权 token
      'Authorization': 'Bearer your-token'
    },
    formData: {
      // 额外的表单参数，如语言、采样率等
      language: 'zh-CN',
      sampleRate: '16000'
    },
    success: (res) => {
      // res.data 是接口返回的字符串
      const result = JSON.parse(res.data);
      console.log('识别结果:', result.text);
    },
    fail: (err) => {
      console.error('上传失败', err);
    }
  });
}
4. 完整流程示例
vue
<template>
  <view>
    <button @click="startRecord">开始录音</button>
    <button @click="stopRecord">停止并识别</button>
    <text>识别结果：{{ resultText }}</text>
  </view>
</template>

<script>
export default {
  data() {
    return {
      recorderManager: null,
      resultText: ''
    };
  },
  onLoad() {
    this.recorderManager = uni.getRecorderManager();
    this.recorderManager.onStop((res) => {
      this.uploadAudio(res.tempFilePath);
    });
  },
  methods: {
    startRecord() {
      this.recorderManager.start({
        duration: 60000,
        sampleRate: 16000,
        numberOfChannels: 1,
        encodeBitRate: 48000,
        format: 'mp3'
      });
    },
    stopRecord() {
      this.recorderManager.stop();
    },
    uploadAudio(filePath) {
      uni.uploadFile({
        url: 'https://your-api.com/recognize',
        filePath: filePath,
        name: 'file',
        header: {
          'Authorization': 'Bearer your-token'
        },
        formData: {
          language: 'zh-CN'
        },
        success: (res) => {
          const data = JSON.parse(res.data);
          this.resultText = data.text;
        },
        fail: (err) => {
          console.error(err);
          uni.showToast({ title: '识别失败', icon: 'none' });
        }
      });
    }
  }
};
</script>
5. 注意事项
录音格式：常见的语音识别接口要求 wav 或 pcm 格式，而 uni-app 默认支持 mp3、aac。若接口要求特定格式，需要转换或在录音时尽量选择接近的格式（如 wav）。如果无法直接得到所需格式，可在后端进行转码。

采样率：必须与识别接口要求一致（通常 16000 或 8000 Hz）。

文件大小：小程序上传文件有大小限制（如微信小程序默认 10MB），确保录音时长不超过限制。

临时文件生命周期：录音的临时文件仅在当前会话有效，建议及时上传或保存。

App 端：在 App 中 uni.uploadFile 同样适用，但路径可能需要转换为绝对路径（如 _doc/、_downloads/）。
