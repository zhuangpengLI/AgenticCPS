# CPS AI 选品工作台

当前版本落地一条可验证的分析与运营草稿链路：聊天页提供“选品分析 / 订单分析”工作台，快捷场景通过 AI Chat 意图路由到 CPS MCP 工具，并将工具结果转换成结构化卡片；所有商品/订单数据仍按只读分析快照处理，只有用户明确操作时才保存筛选条件或选品主题草稿。

## 已实现能力

- `cps_find_resonance_goods`：聚合综合搜索、销量、高佣、2 小时热销、全天热销候选，去重后按来源共振、销量、佣金、优惠券和榜单证据评分。
- `cps_find_alternatives`：在参考价格带内召回候选，按候选佣金、价格相近度、销量和优惠券评分；支持排除原商品，不生成推广链接。
- `cps_analyze_goods_detail`：对当前搜索候选做价格带、优惠券覆盖、佣金、销量和平台分布分析，返回候选理由、风险和数据限制；不伪造历史价格或转化率。
- `cps_analyze_order_profile`：从登录上下文获取当前会员，聚合最近订单的 GMV、返利、平台、价格带、热销商品和分析结论；不接受请求体中的 `memberId`，不推断无数据支撑的人群属性。
- `cps_analyze_order_trend`：按日或按周聚合可信订单，输出订单数、GMV、客单价、预计/实际返利、峰值和环比变化，并明确数据限制。
- AI Chat 快捷入口：从榜单选品、指定条件筛选、应季商品、高佣替代品、成交画像、成交复盘、品类趋势、佣金收益分析；工具执行期间展示任务步骤、完成度、失败原因和只读重试入口。
- 结构化结果块：选品报告、高佣替代品报告、成交画像、成交趋势、商品推荐、比价、返利汇总和后续动作卡片；刷新后仍可从结构化块恢复摘要。
- 运营辅助：筛选条件可复用现有选品主题草稿持久化，支持再次分析、删除；结构化结果可导出 UTF-8 CSV。商品卡片的确认/撤销会按租户、登录管理员和“持久化消息 ID + 结构化块 ID”写入服务端复核状态，记录商品身份、最后操作人、时间和备注；不触发转链、归因或资产变动。当前表保存最新复核状态，不等同于不可变操作历史。
- 保存条件刷新：保存选品条件时可填写结构化关键词、价格/佣金/销量约束并开启自动刷新；手动入口为 `POST /cps/selection-theme/ai-saved-filters/refresh?id=...`，Quartz 处理器为 `cpsAiSavedFilterRefreshJob`（建议每 30 分钟执行）。
- 刷新安全边界：定时任务只处理 `autoRefresh=true` 且包含关键词、类目或明确供应商主题的规则；仅有自然语言 prompt 的历史条件标记为 `SKIPPED`，不会把 prompt 当成搜索词。规则字段采用白名单和范围校验，供应商列表地址仅接受已配置的相对接口路径；刷新使用带超时接管和写库前续租校验的 CAS 租约，旧任务不能覆盖后续任务状态。成功召回非空结果后，未再次召回的普通自动快照会停用；后续再次命中时可自动恢复。经过人工排序、置顶、停用或来自非自动来源的商品保持不变。

## 业务边界

选品结果、价格、优惠券、佣金和销量属于营销分析快照，只用于运营决策和推荐展示，不得直接驱动推广归因、订单结算、返利冻结/扣减、提现或 Token 兑换。推广链接生成仍由显式的高风险工具负责，并继续使用登录会员和幂等上下文。

## 后续迭代

1. 用真实平台数据回放校准共振、替代、商品深度分析与趋势结论。
2. 视审计要求增加 append-only 的不可变复核事件历史，并将“按确认状态生成主题草稿”收敛为服务端单事务接口。
3. 用真实平台数据回放校准评分权重，记录来源覆盖率、点击率、转化率和有效返利等指标，但不改变资金事实来源。

新增 MCP 工具时需同步 `CpsMcpToolConfiguration`、`CpsMcpToolRiskRegistry`、`backend/sql/module/ai-all.sql` 和 `backend/sql/module/ai-update.sql`，并补充工具函数、结构化结果和契约测试。
