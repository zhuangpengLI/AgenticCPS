# AI 使用说明

本文用于指导 AI Agent、MCP 或自动化工具使用本项目的开放平台接口文档。目标是根据用户意图快速选择接口分类，并给出可靠的调用建议。

## 使用目标

- 根据用户需求判断业务场景。
- 从现有文档中定位合适的接口分类。
- 提醒调用前需要的密钥、权限和后续接口。
- 避免编造接口路径、参数或返回字段。

## 接口选择规则

- 先判断用户的业务目标，再选择接口分类。
- 不确定接口分类时，先查 [接口目录](接口目录.md)。
- 涉及密钥、签名、权限、平台差异时，查 [平台接入规则与接口选择](平台接入规则与接口选择.md)。
- 需要具体路径、参数、返回字段时，只从对应分类文档中提取。
- 如果文档中没有明确字段，不要自行补全，应提示以正式接口文档为准。

## 鉴权和权限规则

- 普通接口通常使用 `apikey`。
- 增值类接口通常使用 `appkey` + `appsecret`，并需要签名。
- 京东、拼多多、唯品会、抖音接口通常需要提前申请权限。
- 美团、本地生活、淘宝闪购、官方账号授权类接口通常需要额外确认权限。
- 订单查询、订单拉取、佣金同步类接口通常需要单独确认权限。

## 推荐调用流程

```text
商品导购：商品搜索 -> 商品详情 -> 商品转链 -> 订单查询
活动推广：活动转链 -> 推广链接分发 -> 订单查询
口令识别：口令解析 -> 识别商品或活动 -> 转链
本地生活：活动/店铺/商品查询 -> 转链 -> 订单查询
AI 工具：识别用户意图 -> 选择接口分类 -> 查询具体接口 -> 返回结构化建议
```

## 输出要求

- 优先说明应查看的接口分类和具体接口。
- 说明所需密钥类型和可能的权限要求。
- 提醒必填参数、常见后续接口和错误处理入口。
- 输出要简洁，避免复述大段文档内容。
- 不要编造不存在的接口、字段、参数、状态码或调用示例。

## 错误处理规则

- 鉴权失败：检查 `apikey`、`appkey`、`appsecret` 或签名。
- 权限失败：检查目标平台或订单类权限是否开通。
- 参数错误：检查对应接口文档中的必填参数。
- 请求方式错误：检查接口要求的 `GET`、`POST form-data` 或 `POST JSON`。
- 状态码异常：查看 [错误码与状态码](错误码与状态码.md)。
