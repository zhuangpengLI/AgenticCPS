# 平台接入规则与接口选择

本文面向开发者，说明接入各个平台前需要确认的规则，以及不同业务目标应优先使用哪些接口。接口名称为能力名称，具体接口路径、字段和签名参数以正式接口文档为准。

## 通用接入规则

### 密钥规则

| 接口类型 | 密钥 | 请求方式 | 适用能力 |
|----------|------|----------|----------|
| 普通接口 | `apikey` | `GET` 或 `POST form-data` | 商品搜索、商品详情、商品列表、普通转链、活动转链、部分订单查询 |
| 增值类接口 | `appkey` + `appsecret` | `POST JSON` + 签名 | 淘口令解析、粘贴板识别、短链接生成、CMS 推广链接、部分订单拉取 |
| 特殊权限接口 | 按平台分配 | 按接口要求 | 抖音、京东、拼多多、唯品会、美团、淘宝闪购、本地生活特权、官方账号授权类接口 |

### 推荐调用流程

| 业务目标 | 推荐接口顺序 |
|----------|--------------|
| 做商品搜索导购 | 商品搜索 -> 商品详情 -> 商品转链 -> 订单查询 |
| 做活动推广 | 活动转链 -> 推广链接分发 -> 订单查询 |
| 做口令识别 | 口令解析 -> 商品详情或活动识别 -> 转链 |
| 做本地生活推广 | 平台活动/店铺/商品查询 -> 转链 -> 订单查询 |
| 做 AI 工具或 MCP | 商品搜索 -> 商品详情 -> 转链 -> 口令解析 |

### 权限检查

接入前需要确认：

- 应用是否已创建，并拿到正确的 `apikey`。
- 是否需要增值接口，如果需要，应创建增值应用并保存 `appkey`、`appsecret`。
- 抖音、京东、拼多多、唯品会接口是否已经申请并开通权限。
- 目标平台是否需要官方账号授权或人工开通。
- 订单查询接口是否已开通，因为订单类接口通常比商品类接口权限更严格。
- 请求方式是否匹配接口类型，普通接口和增值接口不要混用密钥。

## 综合电商平台

### 淘宝

| 接入目标 | 需要使用的接口 | 接入规则 |
|----------|----------------|----------|
| 搜索淘宝商品 | 淘宝商品搜索 | 使用普通接口，携带 `apikey`。 |
| 展示商品详情 | 淘宝单品详情 | 搜索结果进入详情页时调用。 |
| 生成推广链接 | 淘宝商品转链 | 需要传入商品链接、商品 ID 或接口要求的推广参数。 |
| 推广会场活动 | 淘宝会场转链 | 适合首页活动、专题页、频道页推广。 |
| 识别淘口令 | 淘口令解析、粘贴板识别 | 通常属于增值类接口，使用 `appkey` 和 `appsecret` 签名。 |
| 查询订单 | 淘宝订单拉取 | 可能属于增值类或特殊权限接口，接入前确认订单权限。 |

### 京东

京东接口需要先申请并开通权限，未开通时不要直接上线调用。

| 接入目标 | 需要使用的接口 | 接入规则 |
|----------|----------------|----------|
| 搜索京东商品 | 京东商品搜索 | 需先申请京东接口权限，开通后按接口要求携带 `apikey`。 |
| 展示商品详情 | 京东商品搜索/详情 | 搜索和详情使用同一个接口；不传关键词时可作为列表使用，用于商品详情页、比价展示和列表展示。 |
| 生成推广链接 | 京东商品转链 | 传入商品链接或商品标识，生成京东推广链接。 |
| 推广活动 | 京东活动/外卖转链 | 用于频道、会场或活动页分发。 |
| 查询订单 | 京东订单拉取 | 需要确认订单查询权限和同步周期。 |

## 常见接入问题

### `apikey` 验证失败

通常检查以下内容：

- 是否已经在「我的应用」创建应用。
- 请求里是否携带正确的 `apikey`。
- 当前接口是否是普通接口，增值接口不能只传 `apikey`。
- 请求方式是否符合接口要求。

### 提示未开通官方账号

说明目标平台或接口需要额外权限。需要联系平台人员开通对应平台授权，再重新调用接口。

### 查不到订单

通常检查以下内容：

- 是否已经开通订单接口权限。
- 推广链接是否由当前账号或当前应用生成。
- 订单是否还在平台同步延迟期。
- 查询时间范围、分页参数、订单状态是否正确。

### 转链失败

通常检查以下内容：

- 商品或活动链接是否属于目标平台。
- 是否传入接口要求的推广位、渠道或 PID 参数。
- 当前平台是否需要官方授权。
- 原链接是否已经失效或不支持推广。
