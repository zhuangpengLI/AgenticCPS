# 接口目录

本文用于帮助开发者和 AI 快速定位应使用的接口分类。这里只放接口索引和跳转说明，具体请求方式、参数、返回字段和示例请查看对应分类文档。

## 使用方式

1. 先根据业务目标选择接口分类。
2. 再打开对应分类文档，查看平台、权限要求和接口说明。
3. 如果接口标记为“需申请权限”，应先确认平台权限已开通。
4. 最后再根据正式接口文档补充接口路径、请求参数、响应字段和代码示例。

## 权限提醒

以下平台接口需要先申请并开通权限：

- 京东
- 拼多多
- 唯品会
- 抖音

以下能力通常也需要额外确认权限：

- 订单查询/订单拉取
- 增值类接口
- 美团、淘宝闪购、本地生活特权接口
- 官方账号授权类接口

## 接口选择速查

| 用户需求 | 优先查看 |
|----------|----------|
| 搜索商品 | 商品接口 |
| 展示商品详情 | 商品接口 |
| 把商品链接变成推广链接 | 转链接口 |
| 推广大促会场或活动页 | 活动接口 |
| 查询推广订单 | 订单接口 |
| 解析淘口令、抖音口令、快手口令 | 口令与工具接口 |
| 生成短链接或 CMS 推广链接 | 口令与工具接口 |
| 接入外卖、酒店、票务、餐饮优惠 | 本地生活接口 |
| 处理接口报错或失败重试 | 错误码与状态码 |
