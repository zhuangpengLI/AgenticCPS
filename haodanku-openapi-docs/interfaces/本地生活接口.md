# 本地生活接口

本文整理外卖、到店、酒店、出行、票务、餐饮和茶饮优惠相关接口。接口路径、完整参数和响应字段以正式接口文档为准。

## 通用规则

- 主要用途：推广本地生活服务、优惠券、酒店住宿、票务和出行服务。
- 常见鉴权：普通接口、特殊权限接口或官方账号授权类接口，按平台要求决定。
- 权限提醒：本地生活平台通常需要先确认权限或账号授权。
- 常见后续接口：转链、订单查询、口令解析。

## 接口详情

### 美团活动列表

- 适用平台：美团
- 适用场景：获取美团活动列表数据，用于展示可推广活动并选择活动进行转链。
- 权限要求：需确认美团平台权限，使用 apikey 鉴权。
- 请求方式：GET
- 接口路径：v3.api.haodanku.com/meituan_activity_list
- 必填参数：无
- 可选参数：apikey、min_id(分页)、back(每页返回条数，可选 1、2、10、20、50、100)
- 返回核心字段：activity_id(活动ID)、activity_name(活动名称)、activity_desc_private(活动描述)、activity_image(活动主图)、start_time(活动开始时间)、end_time(活动结束时间)、min_id(下一页参数)
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 暂无，按通用状态码处理。
- 常见后续接口：美团活动转链、美团订单拉取。
- 注意事项：`back` 只能在指定值中选择；分页时使用返回的 `min_id` 继续拉取下一页；官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=165。

### 美团活动转链

- 适用平台：美团
- 适用场景：将美团活动、活动链接、外卖商品券、买菜业务链接或活动物料生成推广链接。
- 权限要求：需确认美团平台权限，使用 apikey 鉴权。
- 请求方式：POST
- 接口路径：v3.api.haodanku.com/meituan_ratesurl
- 必填参数：apikey
- 可选参数：activity_id(美团活动列表接口获取的活动ID，和活动链接二选一，不可全填)、link_type(链接类型：1.H5链接，2.deeplink唤起链接，3.中间页唤起链接，4.微信小程序唤起路径，默认H5链接)、text(活动链接)、skuViewId(商品skuViewId)、channel(子渠道，1-18字符，仅支持英文、下划线、数字)
- 返回核心字段：url(推广链接)
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 转链失败：检查 `activity_id`、`text`、链接类型、平台权限和渠道参数。
- 常见后续接口：美团订单拉取、短链接生成。
- 注意事项：`activity_id` 和 `text` 二选一，不可全填；`text` 仅支持到家外卖商品券、买菜业务类型链接和活动物料链接，文本中仅存在一个 http 协议头链接；官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=166。

### 淘宝闪购会场转链

- 适用平台：淘宝闪购
- 适用场景：淘宝闪购会场转链，获取淘宝闪购活动推广信息。
- 权限要求：需确认淘宝闪购平台权限，使用 apikey 鉴权。
- 请求方式：POST
- 接口路径：v3.api.haodanku.com/elm_activity_ratesurl
- 必填参数：apikey
- 可选参数：activity_id(活动ID，不填默认生成天天领红包活动会场)、sid(第三方会员ID，1-15字符，仅支持英文、下划线、数字)、link(待转换内容，可将淘宝闪购推广口令或推广链接解析并转成自己的推广内容)
- 返回核心字段：title(会场标题)、description(会场描述)、h5_short_link(分享短链接)、h5_url(分享链接)、mini_qrcode(微信小程序码)、start_time(活动开始时间)、end_time(活动结束时间)、picture(推广图)、wx_appid(小程序appid)、wx_path(小程序path链接)、full_taobao_word(带文案淘口令)、tb_scheme_url(淘宝唤端链接)、ele_scheme_url(饿了么唤端链接)、alipay_mini_url(支付宝唤端链接)
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 转链失败：检查活动 ID、口令/链接内容、平台权限和渠道参数。
- 常见后续接口：淘宝闪购订单拉取。
- 注意事项：`link` 和 `activity_id` 共存时，`activity_id` 优先级高；`link` 仅支持活动会场的口令或链接解析；带文案淘口令有效期 30 天，建议到期前重新获取；官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=153。

### 同程酒店转链

- 适用平台：同程酒店
- 适用场景：获取同程酒店推广链接，用于酒店活动推广和订单归因。
- 权限要求：需确认同程酒店平台权限，使用 apikey 鉴权。
- 请求方式：POST
- 接口路径：v3.api.haodanku.com/tchotel_ratesurl
- 必填参数：apikey
- 可选参数：channel(自有平台代理标识，传入订单接口同步返回，1-20字符，仅支持英文、下划线、数字)
- 返回核心字段：activityId(活动ID)、name(活动名称)、activityUrl(微信小程序路径)、activityH5Url(H5推广链接)、beginTime(活动开始时间)、endTime(活动结束时间)、posterUrl(活动海报)、pictureUrl(活动头图)、shareContext(分享文案)
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 转链失败：检查同程酒店权限、渠道参数和活动状态。
- 常见后续接口：同程酒店订单拉取。
- 注意事项：H5 推广方式可能导致跟单失败，建议使用小程序方式推广；官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=251。

### 本地生活特权转链

- 适用平台：本地生活特权
- 适用场景：本地生活周边吃喝玩乐推广转链，覆盖肯德基、麦当劳、奈雪的茶、喜茶、华莱士、星巴克、瑞幸咖啡、电影票等餐饮/娱乐/休闲内容。
- 权限要求：需确认本地生活特权平台权限，使用 apikey 鉴权。
- 请求方式：POST
- 接口路径：v3.api.haodanku.com/hv_ratesurl
- 必填参数：apikey、platform(平台ID：1.星巴克，2.华莱士，3.瑞幸咖啡，4.汉堡王，5.肯德基，6.喜茶，7.电影票，8.奈雪的茶，9.麦当劳)
- 可选参数：channel(自有平台代理标识，传入订单接口同步返回，1-30字符，仅支持英文、下划线、数字)
- 返回核心字段：name(当前推广平台名称)、link(推广链接)
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 转链失败：检查平台 ID、平台权限和渠道参数。
- 常见后续接口：本地生活特权订单拉取。
- 注意事项：肯德基外送服务正在维护升级中，暂不可用，下单会自动取消；外送订单配送费不参与佣金计算；官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=144。
