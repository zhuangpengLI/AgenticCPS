# 订单接口

本文整理推广订单查询、订单拉取和佣金同步类接口。接口路径、完整参数和响应字段以正式接口文档为准。

## 通用规则

- 主要用途：同步推广订单、订单状态、佣金、结算状态。
- 常见鉴权：普通接口或增值类接口，按平台和接口要求决定。
- 权限提醒：订单类接口通常需要单独确认权限。
- 注意事项：订单同步可能存在平台延迟，查询时应关注时间范围、分页参数和订单状态。

## 接口详情

### 京东订单拉取(官方高佣账号)

- 适用平台：京东
- 适用场景：获取已推广的京东官方高佣账号商品订单数据，用于订单同步、佣金统计、结算状态追踪。
- 权限要求：需申请京东接口权限，开通后使用 apikey 鉴权。
- 请求方式：GET
- 接口路径：v3.api.haodanku.com/unify_jd_order_list
- 必填参数：apikey、min_id(页码)、back(每页条数，最大100条)、start_date(开始时间，Unix时间戳)、end_date(结束时间，Unix时间戳)
- 可选参数：date_type(时间类型：1.付款时间，2.结算时间，4.更新时间，默认付款时间)、state(订单状态：0.全部，1.已付款，2.已结算，3.已退款)
- 返回核心字段：min_id(下一页)、trade_id(子订单号)、trade_parent_id(父订单号)、item_id(商品ID)、earning_time(结算时间)、order_status(订单状态：1.已付款，2.已结算，3.退款/无效，4.已完成)、shop_name(店铺名称)、item_title(商品标题)、item_img(商品图片)、paid_time(付款时间)、create_time(创建时间)、settled_status(好单库结算状态：0.待结算，1.已结算，2.不予结算)、settled_at(结算时间)、pay_price(付款金额)、predict_money(预估佣金)、actual_money(实际佣金)、sub_union_id(渠道信息)、commission_rate(原始佣金比例)
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 暂无，按通用状态码处理。
- 常见前置接口：京东商品转链、京东活动转链。
- 注意事项：`start_date` 和 `end_date` 使用 Unix 时间戳；查询时间含义由 `date_type` 决定；分页时使用返回的 `min_id` 继续拉取下一页；不予结算可能由订单无效或佣金小于 `0.01` 元导致；官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=239。
