# 商品接口

本文整理商品搜索、商品详情和商品列表类接口。接口路径、完整参数和响应字段以正式接口文档为准。

## 通用规则

- 主要用途：按关键词、类目、频道或平台条件获取可推广商品。
- 常见鉴权：普通接口使用 `apikey`。
- 权限提醒：京东、拼多多、唯品会、抖音接口需要先申请并开通权限。
- 接口差异：淘宝的商品搜索、商品详情、商品列表是独立接口；除淘宝外，其他平台的商品搜索和商品详情使用同一个接口。
- 常见后续接口：商品转链、订单查询。

### 淘宝商品列表

- 适用平台：淘宝
- 适用场景：通常用户在搜索页、频道页、类目页点击商品列表时，调用本接口获取商品列表。
- 权限要求：普通接口，使用 apikey 鉴权。
- 请求方式：GET
- 接口路径：v2.api.haodanku.com/column
- 必填参数：apikey、min_id(分页)、back(每页返回条数)
- 可选参数：type(商品筛选类型：type=1是今日上新（当天新券商品），type=2是9.9包邮，type=3是30元封顶，type=4是聚划算，type=5是淘抢购，type=6是0点过夜单，type=7是预告单，type=8是品牌单，type=9是天猫商品，type=10是视频单，type=11是天猫超市单，type=12是偏远地区包邮单，type=13是淘宝商品，type=14是天猫国际，type=15是阿里健康大药房)、sort(0.综合（最新），1.券后价(低到高)，2.券后价（高到低），3.券面额（高到低），4.月销量（高到低），5.佣金比例（高到低），6.券面额（低到高），7.月销量（低到高），8.佣金比例（低到高），9.全天销量（高到低），10全天销量（低到高），11.近2小时销量（高到低），12.近2小时销量（低到高），13.优惠券领取量（高到低），14.好单库指数（高到低）)、cid(商品类目：0全部，1女装，2男装，3内衣，4美妆，5配饰，6鞋品，7箱包，8儿童，9母婴，10居家，11美食，12数码，13家电，14其他，15车品，16文体，17宠物)、price_min、price_max、sale_min、sale_max、coupon_min、coupon_max
- 返回核心字段：itemid、itemtitle、itemshorttitle、itemprice(商品原价)、itemendprice(券后价)、itemsale(销量)、itempic(主图)、tkrates(佣金比)、tkmoney(佣金)、couponmoney(优惠券金额)
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 暂无，按通用状态码处理。
- 常见后续接口：淘宝商品转链、淘宝单品详情。
- 注意事项：暂无。官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=21。

- 请求方式：GET

- 必填参数：apikey、product_id

- 返回核心字段：product_id、itemtitle、itemprice、itemendprice、itempic、itemsale、ksmoney(佣金金额)、ksrates(佣金比率)、ks_images(轮播图集合,数组格式)、ks_detail_imgs(详情图集合,数组格式)、brand_name

- 常见后续接口：快手商品转链、快手口令解析。
