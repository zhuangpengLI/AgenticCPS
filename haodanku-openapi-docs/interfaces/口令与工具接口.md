# 口令与工具接口

本文整理口令解析、粘贴板识别、短链接生成和 CMS 推广链接生成等工具类接口。接口路径、完整参数和响应字段以正式接口文档为准。

## 通用规则

- 主要用途：识别用户粘贴内容、解析平台口令、生成更适合分发的推广链接。
- 常见鉴权：部分接口属于增值类接口，使用 `appkey` 和 `appsecret` 签名。
- 常见后续接口：商品详情、商品转链、活动转链、订单查询。

## 接口清单

| 平台 | 接口能力 | 权限要求 | 推荐后续接口 |
|------|----------|----------|--------------|
| 淘宝 | 口令解析 | 增值类接口 | 淘宝单品详情、淘宝商品转链 |
| 通用 | 粘贴板识别 | 增值类接口 | 商品详情、商品转链、活动转链 |
| 抖音 | 抖音电商口令解析 | 需申请抖音接口权限 | 抖音商品搜索/详情、抖音商品转链 |
| 快手 | 快手口令解析 | 普通接口或按平台权限要求 | 快手商品搜索/详情、快手商品转链 |
| 淘宝闪购 | 淘宝闪购会场转链/解析 | 需确认平台权限 | 淘宝闪购活动或订单接口 |
| 美团 | 美团单品查询并转链 | 需确认平台权限 | 美团转链、美团订单拉取 |
| 通用 | 短链接生成 | 增值类接口 | 推广链接分发 |

## 接口详情

### 口令解析

- 适用平台：淘宝
- 适用场景：解析淘口令，获取口令中的商品数据、优惠券、活动链接、佣金和商品信息。
- 权限要求：增值类接口，使用 app_id、sign 等签名鉴权。
- 请求方式：POST json
- 接口路径：https://v3.api.haodanku.com/rest
- 必填参数：method(固定为 analyze.taoword)、app_id、sign、date(格式为 yyyy-MM-dd HH:mm:ss)、taoword(需要解析的淘口令)
- 可选参数：accurate(是否使用精准解析：0.否，1.是，默认0)
- 返回核心字段：itemid(商品ID)、click_url(二合一链接)、activityid(活动ID)、couponurl(优惠券链接)、activity_url(活动链接)、item_url(商品链接)、tkrates(佣金比例)、itemprice(商品价格)、itemendprice(商品券后价)、itempic(商品主图)、couponmoney(优惠券金额)、itemtitle(商品标题)、itemshorttitle(商品短标题)、itemdesc(描述信息)、biz_scene_id(业务场景ID)、pub_activity_id(官方会场ID)
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 口令解析失败：检查淘口令内容、签名、应用权限和是否需要精准解析。
- 常见后续接口：淘宝单品详情、淘宝商品转链、淘宝会场转链。
- 注意事项：不使用精准解析可提升接口响应速度；获取官方会场 ID 时 `accurate` 需为 `0`；官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=97。

### 短链接生成

- 适用平台：通用
- 适用场景：将需要分享的长链接转换为短链接，便于站外分发和内容推广。
- 权限要求：增值类接口，使用 app_id、sign 等签名鉴权。
- 请求方式：POST json
- 接口路径：https://v3.api.haodanku.com/rest
- 必填参数：method(固定为 short.link)、app_id、sign、date(格式为 yyyy-MM-dd HH:mm:ss)、link(待转换原链接，需 urlencode 后传入)
- 可选参数：无
- 返回核心字段：link(生成的短链接)
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 生成失败：检查原链接是否已 urlencode、签名是否正确、增值接口权限是否开通。
- 常见后续接口：推广链接分发。
- 注意事项：原链接必须 urlencode 后传入；官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=102。

### 粘贴板识别

- 适用平台：通用
- 适用场景：解析用户粘贴的商品链接、平台口令或分享文案，支持淘宝、京东、拼多多、美团、快手、淘宝闪购、抖音等平台，并可转换为自己的分享内容。
- 权限要求：增值类接口，使用 app_id、sign 等签名鉴权。
- 请求方式：POST json
- 接口路径：https://v3.api.haodanku.com/rest
- 必填参数：method(固定为 analyze.clipboard)、app_id、sign、date(格式为 yyyy-MM-dd HH:mm:ss)、content(待解析文案)、is_change(是否转换：0.否，1.是)
- 可选参数：v(版本号，v=3.0.1 时支持美团、快手、淘宝闪购等平台解析和 platform 参数)、platform(指定平台：0.自动识别，1.淘宝，2.京东，3.拼多多，4.美团，5.快手，6.淘宝闪购，7.抖音)、tb_name、tb_pid、tb_rid、jd_union_id、jd_pid、jd_sub_union_id、pdd_union、pdd_pid、channel
- 返回核心字段：item_id(商品ID)、click_url(券链接)、item_url(商品链接)、item_title(商品标题)、item_price(商品原价)、rates(佣金比例)、item_pic(商品图片)、trans_url(转链后的链接类结果)、trans_tpwd(转链后的口令类结果)、platform(对应平台)、item_end_price(券后价/到手价)、month_sale(月销量)、shop_name(店铺名称)、coupon_money(优惠券金额)、coupon_start_time、coupon_end_time、coupon_info、min_buy(多拍件数)
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 识别失败：检查内容格式、指定平台、版本号和平台权限。
  - 转换失败：检查 `is_change`、平台必填推广参数和授权账号。
- 常见后续接口：商品详情、商品转链、活动转链、订单查询。
- 注意事项：转换淘系内容时 `tb_name` 和 `tb_pid` 必填；转换京东内容时 `jd_union_id` 和 `jd_pid` 必填；转换拼多多内容时 `pdd_union` 和 `pdd_pid` 必填；指定平台可提升解析速度；官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=103。

### 抖音电商口令解析

- 适用平台：抖音
- 适用场景：解析抖音电商商品口令，获取商品、直播间、活动页等物料信息，并可生成 deeplink、二维码、抖音口令、zlink、ShareLink。
- 权限要求：需申请抖音接口权限，使用 apikey 鉴权。
- 请求方式：POST form-data
- 接口路径：https://v3.api.haodanku.com/dy_analyze_code
- 必填参数：apikey、content(抖音电商商品口令)
- 可选参数：无
- 返回核心字段：goods_id(抖音电商商品ID)
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - `5001`：商品没有加入精选联盟，解析成功但商品没佣金。
  - `5002`：上游服务异常。
  - `500`：解析失败，通常为错误内容或无效口令。
  - 抖音权限未开通：先申请并开通抖音接口权限。
- 常见后续接口：抖音商品搜索/详情、抖音商品转链、抖音订单拉取。
- 注意事项：不需要二维码时不要传二维码相关 `share_type`，二维码生成耗时较高；官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=109。

### 快手口令解析

- 适用平台：快手
- 适用场景：解析快手电商商品口令，获取快手商品 ID。
- 权限要求：普通接口或按平台权限要求，使用 apikey 鉴权。
- 请求方式：POST form-data
- 接口路径：https://v3.api.haodanku.com/ks_analyze_code
- 必填参数：apikey、content(快手商品口令)
- 可选参数：无
- 返回核心字段：product_id(快手商品ID)
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 解析失败：检查快手口令内容、平台权限和商品状态。
- 常见后续接口：快手商品搜索/详情、快手商品转链、快手订单拉取。
- 注意事项：官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=163。

### 淘宝闪购会场转链/解析

- 适用平台：淘宝闪购
- 适用场景：解析淘宝闪购活动会场口令或推广链接，并转换为自己的推广内容；也可直接生成淘宝闪购会场推广信息。
- 权限要求：需确认淘宝闪购平台权限，使用 apikey 鉴权。
- 请求方式：POST
- 接口路径：https://v3.api.haodanku.com/elm_activity_ratesurl
- 必填参数：apikey form-data
- 可选参数：activity_id(活动ID，不填默认生成“天天领红包”活动会场)、sid(第三方会员ID，1-15字符，仅支持英文、下划线、数字)、link(待转换内容，可解析淘宝闪购推广口令或推广链接)
- 返回核心字段：title(会场标题)、description(会场描述)、h5_short_link(分享短链接)、h5_url(分享链接)、mini_qrcode(微信小程序码)、start_time(活动开始时间)、end_time(活动结束时间)、picture(推广图)、wx_appid(小程序appid)、wx_path(小程序path链接)、full_taobao_word(带文案淘口令)、tb_scheme_url(淘宝唤端链接)、ele_scheme_url(饿了么唤端链接)、alipay_mini_url(支付宝唤端链接)
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 解析失败：检查 `link` 是否为活动会场口令或链接。
  - 转链失败：检查活动 ID、平台权限和渠道参数。
- 常见后续接口：淘宝闪购订单拉取。
- 注意事项：`link` 和 `activity_id` 共存时，`activity_id` 优先级高；`link` 仅支持活动会场的口令或链接解析；带文案淘口令有效期 30 天，建议到期前重新获取；官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=153。

### 美团单品查询并转链

- 适用平台：美团
- 适用场景：解析美团分享链接，获取对应商品详情并转链生成推广链接。
- 权限要求：需确认美团平台权限，使用 apikey 鉴权。
- 请求方式：POST form-data
- 接口路径：https://v3.api.haodanku.com/mt_goods_detail
- 必填参数：apikey、text(待解析内容)
- 可选参数：link_type(链接类型，支持多个类型用英文逗号分隔：1.H5长链接，2.H5短链接，3.deeplink唤起链接，4.微信小程序唤起路径，5.团口令，6.小程序码；默认1)、channel(渠道信息，1-18字符，仅支持英文、下划线、数字)
- 返回核心字段：searchId(下一页请求入参)、detail_info(商品信息)、availablePoiNum(可用门店数量)、availablePoiCityNum(可用城市数量)、brandName(品牌名称)、brandLogoUrl(品牌Logo)、name(商品名称)、couponNum(券包中券数量)、headUrl(商品头图)、saleVolume(累计销量)、startTime(活动有效期开始时间)、endTime(活动有效期结束时间)、originalPrice(原始价格)、sellPrice(售卖价格)、referral_link(转链内容)、commissionPercent(佣金比例)、commission(佣金金额)
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 解析失败：检查 `text` 中的链接类型和内容格式。
  - 转链失败：检查美团平台权限、`link_type` 和渠道参数。
- 常见后续接口：美团订单拉取、短链接生成。
- 注意事项：`text` 支持到家外卖商品券、医药商品链接、到店美食、休闲生活、酒店、门票商品链接和活动物料链接；链接类型支持长链、短链、deeplink、圈圈小程序唤起路径、美团小程序活动链接；官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=296。
