# 活动接口

本文整理会场、频道、主题活动类接口。接口路径、完整参数和响应字段以正式接口文档为准。

## 通用规则

- 主要用途：生成平台活动页、会场页、频道页的推广链接。
- 常见鉴权：普通接口使用 `apikey`，部分平台活动接口需要额外权限。
- 权限提醒：京东、拼多多、唯品会、抖音接口需要先申请并开通权限。
- 常见后续接口：短链接生成、订单查询。

## 接口清单

| 平台 | 接口能力 | 权限要求 | 推荐后续接口 |
|------|----------|----------|--------------|
| 淘宝 | 淘联会场转链 | 普通接口 | 淘宝订单拉取、短链接生成 |
| 淘宝闪购 | 淘宝闪购会场转链 | 需确认平台权限 | 淘宝闪购订单拉取 |
| 京东 | 京东外卖转链 | 需申请京东接口权限 | 京东订单拉取 |
| 拼多多 | 生成营销工具推广链接(官方高佣账号) | 需申请拼多多接口权限 | 拼多多订单拉取 |
| 唯品会 | 唯品会会场转链(官方高佣账号) | 需申请唯品会接口权限 | 唯品会订单拉取 |
| 抖音 | 抖音电商活动转链 | 需申请抖音接口权限 | 抖音订单拉取 |

## 接口详情

### 淘联会场转链

- 适用平台：淘宝
- 适用场景：联盟会场活动转链，用于将淘宝联盟会场活动生成推广链接和淘口令。
- 权限要求：普通接口，使用 apikey 鉴权。
- 请求方式：POST form-data
- 接口路径：http://v2.api.haodanku.com/createConference_code
- 必填参数：apikey、activity_id(会场ID)、pid(推广位ID)、tb_name(授权后的淘宝名称)、title(会场短标题，需超过8个字符)
- 可选参数：relation_id(渠道ID)、activity_url(会场链接地址，与 activity_id 二选一；传 activity_url 时无需 tb_name)
- 返回核心字段：url(二合一地址)、tao_code(淘口令)
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 暂无，按通用状态码处理。
- 常见后续接口：淘宝订单拉取、短链接生成。
- 注意事项：`pid` 需是授权淘宝号下的推广位；如果携带渠道 ID 请求，`pid` 需是渠道管理下的渠道专属推广位；官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=12。

### 京东活动转链(京东外卖取链)

- 适用平台：京东
- 适用场景：获取京东活动推广链接，用于京东外卖领券、下单等活动入口推广。
- 权限要求：需申请京东接口权限，开通后使用 apikey 鉴权。
- 请求方式：POST form-data
- 接口路径：https://v3.api.haodanku.com/unify_jditems_link
- 必填参数：apikey、material_id(京东外卖物料链接)
- 可选参数：subUnionId(子渠道标识，仅支持字母、数字、下划线或中划线，最多30个字符，不可包含空格)
- 返回核心字段：shortURL(推广短链接，有效期60天)、clickURL(推广长链接，长期有效)
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 京东权限未开通：先申请并开通京东接口权限。
- 常见后续接口：京东订单拉取。
- 注意事项：`material_id` 传京东外卖活动物料链接；官方文档中热门活动示例包含京东外卖领券页和下单页；官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=280。

### 生成营销工具推广链接(拼多多活动转链)

- 适用平台：拼多多
- 适用场景：生成拼多多营销工具推广链接，支持新人红包、超级红包、千万补贴、千万神券、母婴馆、限时秒杀等活动页面。
- 权限要求：需申请拼多多接口权限，开通后使用 apikey 鉴权。
- 请求方式：POST form-data
- 接口路径：https://v3.api.haodanku.com/unify_pddpromurl_generate
- 必填参数：apikey、channel_type(营销工具类型：2.新人红包，3.刮刮卡，5.员工内购，12.砸金蛋，16.千万补贴C端页面，17.千万补贴投票页面，23.超级红包，34.千万神券C端页面，39.母婴馆C端页面，42.超级红包9.9C端活动页，56.限时秒杀C端会场)
- 可选参数：channel(渠道信息，1-20字符，仅支持英文、下划线、数字)、red_packet_goods(超级红包置顶落地页商品，channel_type=23时有效)、tmcc_goods(千万神券置顶落地页商品，channel_type=34时有效)、tmc_config_id(指定活动ID，channel_type=34时有效)、get_short_link(是否返回微信shortLink，1.是；该字段需申请权限)
- 返回核心字段：url(普通推广长链接)、short_url(推广短链接)、schema_url(APP唤起链接)、we_app_info(微信小程序信息)、we_app_icon_url(小程序图片)、user_name(用户名)、page_path(小程序path值)、source_display_name(来源名)、title(小程序标题)、app_id(小程序ID)、desc(描述)、weixin_short_link(微信shortLink)
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 拼多多权限未开通：先申请并开通拼多多接口权限。
  - 活动参数错误：检查 `channel_type`、置顶商品和活动 ID 是否匹配。
- 常见后续接口：拼多多订单拉取。
- 注意事项：`get_short_link` 需要额外权限；千万神券品牌活动商品需要传对应品牌活动的 `tmc_config_id`；官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=195。

### 唯品会会场转链(官方高佣账号)

- 适用平台：唯品会
- 适用场景：获取唯品会会场、商品、专场、店铺、品牌、专题推广链接。
- 权限要求：需申请唯品会接口权限，开通后使用 apikey 鉴权。
- 请求方式：POST form-data
- 接口路径：https://v3.api.haodanku.com/unify_vip_activity_convert
- 必填参数：apikey、url(商品链接、专场链接、店铺链接、品牌链接或专题链接)
- 可选参数：channel(渠道标识，支持字母、数字、下划线，长度小于15)
- 返回核心字段：vipZfbSchemeUrl(唯品会支付宝小程序scheme链接)、vipWxUrl(唯品会微信小程序链接)、deeplinkUrl(CPS Deeplink链接)、vipZfbUrl(唯品会支付宝小程序链接)、url(CPS短链接)、noEvokeLongUrl(不唤起快应用CPS长链接)、noEvokeUrl(不唤起快应用CPS短链接)、vipQuickAppUrl(唯品会快应用链接)、longUrl(CPS长链接)、ulUrl(CPS通用链接)、vipZfbHttpsUrl(唯品会支付宝小程序https链接)、onlyCommand(唯品会唯口令)
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 唯品会权限未开通：先申请并开通唯品会接口权限。
  - 转链失败：检查传入链接类型、渠道参数和账号权限。
- 常见后续接口：唯品会订单拉取。
- 注意事项：`url` 支持商品、专场、店铺、品牌、专题等多类链接；官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=332。

### 抖音电商活动转链

- 适用平台：抖音
- 适用场景：抖音电商活动页转链，获取推广链接、短链接、抖音口令和二维码信息。
- 权限要求：需申请抖音接口权限，开通后使用 apikey 鉴权。
- 请求方式：POST form-data
- 接口路径：https://v3.api.haodanku.com/get_dyactivity_link
- 必填参数：apikey、activity_id(活动类型：1.百亿补贴，2.秒杀活动，3.自建活动页)
- 可选参数：channel(子渠道，1-20字符，仅支持英文、下划线、数字)、mix_activity_id(可推广的运营自建活动页活动ID；activity_id=3时必填)、activity_url(可推广的运营自建活动页链接，支持H5和schema)、product_id(百亿补贴/秒杀置顶商品ID)、platform(回流端标识：0.抖音，1.抖音极速版，默认0)
- 返回核心字段：dy_deeplink(打开抖音APP链接)、share_command(抖音口令)、zlink(短链接)、qr_code(抖音二维码信息)
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 抖音权限未开通：先申请并开通抖音接口权限。
  - 活动参数错误：检查 `activity_id`、`mix_activity_id`、`activity_url` 和置顶商品 ID 是否匹配。
- 常见后续接口：抖音订单拉取、抖音口令解析。
- 注意事项：`activity_id=3` 时 `mix_activity_id` 必填；数据接口需要登录态 `uid` 才能获取，但官方文档地址统一使用页面地址；官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=126。
