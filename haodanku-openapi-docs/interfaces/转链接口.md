# 转链接口

本文整理商品转链、活动转链之外的推广链接生成能力。接口路径、完整参数和响应字段以正式接口文档为准。

## 通用规则

- 主要用途：将商品链接、商品 ID、活动链接或平台素材转换为可追踪的推广链接。
- 常见鉴权：普通接口使用 `apikey`，部分工具型转链可能属于增值类接口。
- 权限提醒：京东、拼多多、唯品会、抖音接口需要先申请并开通权限。
- 常见后续接口：短链接生成、订单查询。

| 平台 | 接口能力 | 权限要求 | 推荐后续接口 |
|------|----------|----------|--------------|
| 淘宝 | 淘宝商品转链 | 普通接口 | 淘宝订单拉取、短链接生成 |
| 京东 | 京东商品转链 | 需申请京东接口权限 | 京东订单拉取、短链接生成 |
| 拼多多 | 拼多多商品转链 | 需申请拼多多接口权限 | 拼多多订单拉取、短链接生成 |
| 唯品会 | 唯品会转链 | 需申请唯品会接口权限 | 唯品会订单拉取、短链接生成 |
| 抖音 | 抖音商品转链 | 需申请抖音接口权限 | 抖音订单拉取、短链接生成 |
| 快手 | 快手商品转链 | 普通接口或按平台权限要求 | 快手订单拉取、短链接生成 |
| 通用 | 短链接生成 | 增值类接口 | 推广链接分发 |
| 通用 | 粘贴板识别 | 增值类接口 | 推广链接分发 |

## 接口详情

### 淘宝商品转链

- 适用平台：淘宝
- 适用场景：通常用户在详情页点击分享或者购买下单按钮时，调用本转链接口。
- 权限要求：普通接口，使用 apikey 鉴权。
- 请求方式：POST form-data
- 接口路径：v3.api.haodanku.com/ratesurl
- 必填参数：apikey、itemid、pid、tb_name(已授权的淘宝账号昵称)、get_taoword(固定=1)、title(商品标题)
- 可选参数：relation_id、special_id
- 返回核心字段：coupon_click_url、item_url、taoword、new_model
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 暂无，按通用状态码处理。
- 常见后续接口：淘宝订单拉取
- 注意事项：relation_id、special_id是区分下单渠道使用，非自定义内容，需要在官方后台或官方接口获取。官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=1。

### 京东商品转链

- 适用平台：京东
- 适用场景：通常用户在京东商品详情页点击分享、领券或购买按钮时，调用本转链接口生成京东推广链接。
- 权限要求：需先申请京东接口权限，开通后使用 apikey 鉴权。
- 请求方式：POST form-data
- 接口路径：https://v2.api.haodanku.com/get_jditems_link
- 必填参数：apikey、material_id(京东联盟商品ID)、union_id(目标推客的联盟ID)。
- 可选参数：coupon_url(优惠券链接)、pid(推广位PID)、subUnionId(渠道标识，仅支持字母、数字、下划线或中划线，最多80个字符且不可包含空格)、proType、scene_id。
- 返回核心字段：data.short_url(推广短链接)。
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 暂无，按通用状态码处理。
- 常见后续接口：京东订单拉取。
- 注意事项：京东接口需提前申请权限；自2024年12月3日起 `material_id` 需传完整的京东联盟商品ID，不能传普通京东SKU；订单归因依赖subUnionId。官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=48。

### 拼多多商品转链

- 适用平台：拼多多
- 适用场景：通常用户在拼多多商品详情页点击分享、领券或购买按钮时，调用本转链接口生成拼多多推广链接。
- 权限要求：普通接口，使用 apikey 鉴权；无需使用官方高佣统一转链接口。
- 请求方式：POST form-data。
- 接口路径：https://v2.api.haodanku.com/get_pdditems_link
- 必填参数：apikey、pid、goods_sign。
- 可选参数：goods_id、owner_id、zs_duo_id、subUnionId。
- 返回核心字段：url(普通推广长链接，唤起H5页面)、short_url(推广短链接)、mobile_url(普通长链，微信环境下进入领券页点领券拉起小程序，浏览器环境下直接拉起APP，未安装拼多多APP时落地页点领券拉起登录页)、mobile_short_url(对应出参mobile_url的短链接，与mobile_url功能一致)、schema_url(使用此推广链接，用户安装拼多多APP的情况下会唤起APP（需客户端支持schema跳转协议）)。
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 暂无，按通用状态码处理。
- 常见后续接口：拼多多订单拉取。
- 注意事项：项目使用普通账号可调用的 v2 转链接口，避免依赖 `unify_pdditems_link` 官方高佣权限。官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=49。

### 唯品会转链

- 适用平台：唯品会
- 适用场景：通常用户在唯品会商品页、品牌会场或活动页点击分享、领券或购买按钮时，调用本转链接口生成唯品会推广链接。
- 权限要求：普通接口，使用 apikey 鉴权；需配置唯品会 PID。
- 请求方式：POST form-data。
- 接口路径：https://v2.api.haodanku.com/vip_ratesurl
- 必填参数：apikey、goodsid、pid。
- 可选参数：relation_id。
- 返回核心字段：url(CPS短链接)、longUrl(CPS长链接)、onlyCommand(唯品会唯口令)、deeplinkUrl(CPS Deeplink链接)。
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 暂无，按通用状态码处理。
- 常见后续接口：唯品会订单拉取。
- 注意事项：项目使用普通账号可调用的 v2 转链接口，避免依赖 `unify_vip_item_convert` 官方高佣权限。官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=69。

### 抖音商品转链

- 适用平台：抖音
- 适用场景：通常用户在抖音商品卡片、商品详情页场景中点击分享、领券或购买按钮时，调用本转链接口生成抖音推广链接。
- 权限要求：需先申请抖音接口权限，开通后使用 apikey 鉴权。
- 请求方式：POST form-data。
- 接口路径：v3.api.haodanku.com/get_dyitem_link
- 必填参数：apikey、itemid。
- 可选参数：share_type(转链类型:0. 全部；1. 抖音 deeplink；2. 抖音二维码；3. 抖音口令；4. 抖音zlink；5. ShareLink【注：不需要二维码请不要填，二维码生成耗时较高】获取多个类型，使用英文逗号隔开入参，例：1,2,3。
按需选择，类型越少响应越快！)、channel(渠道标识（1-50字符，仅支持 英文、"_"、数字）)、platform(0：抖音，1：抖音极速版，不传默认为0)。
- 返回核心字段：dy_deeplink、dy_password(抖音口令)、share_link、dy_zlink。
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 暂无，按通用状态码处理。
- 常见后续接口：抖音订单拉取、抖音口令解析。
- 注意事项：抖音接口需提前申请权限。官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=106。

### 淘宝更高佣商品转链

- 适用平台：淘宝
- 适用场景：对比普通淘宝佣金后获取更高佣，调用本转链接口。
- 权限要求：普通接口，使用 apikey 鉴权。
- 请求方式：POST form-data
- 接口路径：v3.api.haodanku.com/get_tblive_link
- 必填参数：apikey、promotion_id
- 可选参数：link_type(链接类型；默认1。枚举值：1. H5长链接；2. H5短链接；3. 淘口令；4. tbopen淘宝换端链接)、channel(渠道信息。选填（1-30字符，仅支持 英文、"_"、数字）)
- 返回核心字段：deep_link(转链内容对应link_type值)
- 状态码说明：通用状态码详见 [../错误码与状态码.md](../错误码与状态码.md)，本接口特殊状态码见下方。
- 特殊状态码：
  - 暂无，按通用状态码处理。
- 常见后续接口：淘宝更高佣订单拉取
- 注意事项：relation_id、special_id是区分下单渠道使用，非自定义内容，需要在官方后台或官方接口获取。官方文档地址：https://www.haodanku.com/Openapi/api_detail?id=299。
